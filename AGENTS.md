# Project instructions

## Portable project continuity
Read PROJECT.md, HANDOVER.md, WORKLOG.md and CHAT_INDEX.md before continuing work.
Keep the permanent project ID unchanged when moving folders or computers.
After meaningful work, append a dated WORKLOG.md entry with the request, changes,
verification, evidence paths, pending items and chat ID when available. Update
HANDOVER.md with the latest verified position and next steps. Use relative paths.
Treat old chat titles and historical reports as leads, not proof of current state.
Do not record credentials, tokens, private keys or connection secrets.
Do not claim success without evidence or treat prior approval as permission for new
disruptive actions. Be very cautious: most work involves live systems.
These files preserve context; they do not restore original chats or grant access.
